🐧 Welcome to Linux App Service

FastAPI + Uvicorn on Azure

🎉 Your App is Running!

This is a sample Python web application built with FastAPI and Uvicorn, deployed on Azure Linux App Service. It demonstrates real-time system monitoring and environment information.

✨ Features

  • Real-time system resource monitoring
  • Linux environment information
  • Azure App Service metadata
  • Health check endpoint
  • RESTful API endpoints
  • Responsive modern UI
